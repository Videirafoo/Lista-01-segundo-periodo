# Lista de Exercícios — Algoritmos em Python

Trabalho de algoritmos utilizando Python.

## Objetivo

Praticar:

- 1 entrada e saída de dados;
- 2 variáveis;
- 3 operações matemáticas;
- 4 estruturas condicionais;
- 5 estruturas de repetição;
- 6 listas;
- 7 funções.

## Exercícios

1. Operações matemáticas com dois números.
2. Leitura de nome e idade.
3. Número positivo, negativo ou zero.
4. Aprovação ou reprovação de um aluno.
5. Tabuada de 1 a 10.
6. Soma dos números de 1 até um limite.
7. Soma e média de dez números.
8. Soma de vários números até digitar zero.
9. Função que retorna o maior entre dois números.
10. Maior e menor entre cinco números.

## Execute da forma abaixo

Abra o terminal na pasta do projeto e execute:

```bash
python main.py
