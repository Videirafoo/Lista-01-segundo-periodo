# Exercícios de Algoritmos em Python

Repositório acadêmico desenvolvido para praticar fundamentos de **Algoritmos e Lógica de Programação** com Python.

## Conteúdo

Os exercícios trabalham conceitos como:

- entrada e saída de dados;
- variáveis e tipos;
- operações matemáticas;
- estruturas condicionais;
- estruturas de repetição;
- listas;
- funções;
- maior e menor valor;
- soma e média.

## Exercícios

1. Operações matemáticas com dois números.
2. Leitura de nome e idade.
3. Classificação de número positivo, negativo ou zero.
4. Aprovação ou reprovação de um aluno.
5. Tabuada de 1 a 10.
6. Soma dos números de 1 até um limite.
7. Soma e média de dez números.
8. Soma de valores até a entrada do número zero.
9. Função que retorna o maior entre dois números.
10. Maior e menor entre cinco números.

## Estrutura

Cada exercício possui seu próprio arquivo e o `main.py` organiza a execução do conjunto.

```text
exercicio1.py
exercicio2.py
...
exercicio10.py
main.py
```

## Como executar

```bash
python main.py
```

Ou execute um exercício específico:

```bash
python exercicio1.py
```
